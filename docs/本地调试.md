## 起一个临时实例

数据目录和端口都换掉，避免碰到 `data/oh-pmt-api.db`：

```bash
cd ~/Documents/oh-pmt-api
rm -rf /tmp/pmt-dev && mkdir -p /tmp/pmt-dev
PMT_DATA=/tmp/pmt-dev PMT_PORT=8801 python3 src/server.py
```

注意后台进程在多次工具调用之间可能被回收。要跨命令保持运行，写成脚本再 `nohup`：

```bash
cat > /tmp/pmt-dev/up.sh <<'SH'
#!/bin/bash
cd ~/Documents/oh-pmt-api
exec env PMT_DATA=/tmp/pmt-dev PMT_PORT=8801 python3 src/server.py
SH
chmod +x /tmp/pmt-dev/up.sh
nohup /tmp/pmt-dev/up.sh > /tmp/pmt-dev/log.txt 2>&1 &
disown
```

`curl localhost:8801/health` 返回 200 即就绪。

## 播种数据

直接调 `Store` 比走接口快，也能设出接口设不了的字段（比如 `is_admin`）。

```python
import sys; sys.path.insert(0, "src")
from store import Store

s = Store("/tmp/pmt-dev/oh-pmt-api.db")
admin = s.create_member(name="admin", username="admin", password="pw", is_admin=1)
mid   = s.create_member(name="张三", username="u1", password="pw",
                        limit_daily=15, limit_total=100)
s.create_key(member_id=mid, note="测试密钥")

a1 = s.add_account(provider="qoder", uid="q1", region="cn",
                   credential="pt-x", name="Qoder 主号")
a2 = s.add_account(provider="workbuddy", uid="w1", region="cn",
                   credential="{}", name="WorkBuddy A")

for i in range(20):
    s.record_usage(key_id=None, member_id=mid,
                   account_id=a1 if i % 2 else a2,
                   model="glm-5.3" if i % 3 else "kimi-k3",
                   prompt_tokens=800, completion_tokens=200,
                   cost=0.02, credits=0.2, price_source="builtin")
print("ok", mid)
```

工厂函数叫 `create_member`，不是 `add_member`。账号是 `add_account`。

## 登录后台

管理页面要登录态。直接请求 `POST /api/login` 拿 `q2a_session`：

```python
import json, urllib.request, http.cookiejar
jar = http.cookiejar.CookieJar()
op = urllib.request.build_opener(urllib.request.HTTPCookieProcessor(jar))
r = urllib.request.Request("http://127.0.0.1:8801/api/login",
    data=json.dumps({"username": "admin", "password": "pw"}).encode(),
    headers={"Content-Type": "application/json"}, method="POST")
op.open(r, timeout=10).read()
json.dump({"value": next(iter(jar)).value}, open("/tmp/pmt-dev/cookie.json", "w"))
```

浏览器没法带这个 cookie，所以要一层注入代理（约 25 行，写到 `/tmp/pmt-dev/px.py`）：

```python
import http.server, urllib.request, urllib.error, json
CK = json.load(open("/tmp/pmt-dev/cookie.json"))["value"]

class P(http.server.BaseHTTPRequestHandler):
    def _do(self):
        url = "http://127.0.0.1:8801" + self.path
        n = int(self.headers.get("Content-Length") or 0)
        body = self.rfile.read(n) if n else None
        h = {k: v for k, v in self.headers.items()
             if k.lower() not in ("host", "cookie", "content-length")}
        h["Cookie"] = "q2a_session=" + CK
        req = urllib.request.Request(url, data=body, headers=h, method=self.command)
        try:
            with urllib.request.urlopen(req, timeout=20) as r:
                data, st, hd = r.read(), r.status, r.headers
        except urllib.error.HTTPError as e:
            data, st, hd = e.read(), e.code, e.headers
        self.send_response(st)
        for k, v in hd.items():
            if k.lower() not in ("content-length", "transfer-encoding", "connection"):
                self.send_header(k, v)
        self.send_header("Content-Length", str(len(data)))
        self.end_headers()
        self.wfile.write(data)
    do_GET = do_POST = do_PATCH = do_DELETE = _do
    def log_message(self, *a): pass

http.server.ThreadingHTTPServer(("127.0.0.1", 8802), P).serve_forever()
```

然后访问 `http://127.0.0.1:8802/admin` 就是登录态。

## 用无头 Chrome 断言页面

本机没有 playwright/puppeteer，但 Node 自带全局 `WebSocket`，可以直接说 CDP。

```bash
/Applications/Google\ Chrome.app/Contents/MacOS/Google\ Chrome \
  --headless=new --remote-debugging-port=9333 \
  --window-size=1500,950 --user-data-dir=/tmp/pmt-dev/cd \
  > /tmp/pmt-dev/chrome.log 2>&1 &
sleep 5
```

脚本骨架（`/tmp/pmt-dev/probe.mjs`）：

```javascript
const tabs = await (await fetch('http://127.0.0.1:9333/json')).json();
const ws = new WebSocket(tabs.find(t => t.type === 'page').webSocketDebuggerUrl);
let id = 0; const pending = new Map();
ws.addEventListener('message', ev => {
  const m = JSON.parse(ev.data);
  if (m.id && pending.has(m.id)) { pending.get(m.id)(m); pending.delete(m.id); }
});
const cmd = (method, params = {}) => new Promise(res => {
  const my = ++id; pending.set(my, res);
  ws.send(JSON.stringify({ id: my, method, params }));
});
await new Promise(r => ws.addEventListener('open', r));
await cmd('Page.enable'); await cmd('Runtime.enable');
const ev = async e => (await cmd('Runtime.evaluate',
  { expression: e, returnByValue: true, awaitPromise: true })).result.result.value;

await cmd('Emulation.setDeviceMetricsOverride',
  { width: 1500, height: 950, deviceScaleFactor: 1, mobile: false });
await cmd('Page.navigate', { url: 'http://127.0.0.1:8802/admin' });
await new Promise(r => setTimeout(r, 3000));
// 切到某个 section：只有当前 section 在显示，直接查表格会查不到
await ev(`document.querySelector('nav a[data-page="members"]').click(); 1`);
await new Promise(r => setTimeout(r, 900));
console.log(await ev(`getComputedStyle(
  document.querySelector('.member-table tbody tr td:first-child')).backgroundColor`));
ws.close();
```

### 四个必踩的坑

1. **启动时只给 `about:blank`，`/json` 里没有 page target**，`webSocketDebuggerUrl`
   是 undefined。把目标 URL 写进启动命令，或启动后调 `Page.navigate` 再等几秒。
2. **窄视口会触发响应式规则**（`.brand` 在 860px 以下 `display:none`，900px 左右
   表格开始横向溢出）。要验证桌面样式就显式 `Emulation.setDeviceMetricsOverride`
   给 1500×950。
3. **`localStorage` 里设的主题不跨 `Page.navigate` 存活**。要测暗色：
   `localStorage.setItem('ohpmt_theme','dark')` 之后 `Page.reload()`；
   或直接 `document.documentElement.setAttribute('data-theme','dark')`（只影响当前页）。
4. **`/admin` 是单页多 section**，只有当前 section 可见。查表格前先点对应的
   `nav a[data-page="..."]`，并用 `offsetHeight > 16 && width > 80` 过滤隐藏行。

### 验证 CSS 状态用计算样式，不要用截图猜颜色

```javascript
getComputedStyle(el).backgroundColor   // 静态底色
getComputedStyle(el).backgroundImage   // 渐变层（半透明色会在这里）
```

半透明色叠在实底上时，`backgroundColor` 报的是实底色，真正的金色在 `backgroundImage`
的 `linear-gradient(...)` 里。两者都要读。

要模拟悬停，发真实的鼠标事件，然后等几百毫秒：

```javascript
await cmd('Input.dispatchMouseEvent',
  { type: 'mouseMoved', x: rect.x + 300, y: rect.y + 20, button: 'none' });
await new Promise(r => setTimeout(r, 700));
```

### 像素采样（只在需要时用）

从 PNG 里读颜色要自己解码（`zlib` + 逐扫描线反滤波）。两条经验：

- 单个点可能落在字的抗锯齿上。取采样点周围 ±5px 窗口里出现次数最多的颜色。
- 坐标要边界保护，视口外的行会 `IndexError`。
- 优先用 `getComputedStyle`；只有用户给截图、或要证明「弧线真的画出来了」时才下到像素。
